# Green Court Resort — New Year's Eve 2027

Mobile-first static landing page based on the provided design.

## Publish for free with GitHub Pages

1. Create a public GitHub repository.
2. Upload `index.html` and `style.css`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Your page will appear at:
   `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

No paid domain is required.

## Later edits

- Change colors in `style.css` under `:root`.
- Replace the temporary CSS logo in `index.html` with the official logo asset when available.
- Add WhatsApp booking links if desired.
